# 👟 KICKS - Ayakkabı E-Ticaret Uygulaması

KICKS, ayakkabı ürünlerinin listelenebildiği ve detaylarının görüntülenebildiği bir e-ticaret uygulamasıdır. Projede ürün listeleme, ürün detay sayfası ve admin dashboard bölümleri bulunmaktadır. Ayrıca rol tabanlı kimlik doğrulama ve yetkilendirme sistemi kullanılmıştır.

---

## ✨ Özellikler

- Kullanıcı girişi ve kayıt olma
- Ayakkabı ürünlerini listeleme ve detaylarını görüntüleme
- Responsive tasarım
- Yönetici paneli (Admin Dashboard)
- Ürün ekleme, düzenleme ve silme
- Form doğrulama
- Hata ve başarı bildirimleri

---

## 🛠️ Kullanılan Teknolojiler

- React
- TypeScript
- Tailwind CSS
- TanStack Query
- Formik ve Yup
- Axios
- React Router DOM
- React Icons
- DOMPurify
- React-Toastify
